# PLAN

## Этап 0 — бесплатная техническая проверка

- Проверить актуальные правила конкурса и поддержку WebMCP.
- Создать минимальный пример `search_services`.
- Доказать реальный вызов.
- Принять решение `GO/STOP`.

## Этап 1 — безопасный MVP

- Описать строгие входы и выходы трёх инструментов.
- Добавить тестовый каталог услуг.
- Добавить тестовое расписание и проверку доступности.
- Добавить тестовое создание записи с явным подтверждением.
- Покрыть контракты и ошибки тестами.

## Этап 2 — пользовательский сценарий

- Проверить полный путь: услуга → время → подтверждение → запись.
- Проверить отмену действия до подтверждения.
- Проверить повторный запрос, конфликт слота и неверные данные.
- Провести тест через Operator как обычный пользователь.

## Этап 3 — конкурсная упаковка

- Коротко сформулировать проблему и ценность.
- Подготовить воспроизводимую инструкцию запуска.
- Удалить лишнее, проверить лицензии и происхождение кода.
- Записать короткое честное демо без постановочных результатов.

## Этап 4 — финальная проверка

- Чистая установка и повторный запуск.
- Тесты, security/privacy scan и проверка Git diff.
- Проверка соответствия правилам Devpost.
- Код готов не позднее 1 сентября.
- 2 сентября: видео, текст заявки и финальный аудит.
- Отправка до 3 сентября 2026, 13:00 PT.

## Правило управления объёмом

Любая новая функция откладывается, если она не нужна для демонстрации одного из трёх утверждённых инструментов.
