# CHECKPOINT — этап 0

Дата: 2026-08-28 UTC.
Статус: `IN PROGRESS`.

## Уже зафиксировано

- Создано отдельное рабочее пространство конкурса.
- Определён один вертикальный сценарий.
- Зафиксированы три инструмента MVP.
- Основные проекты объявлены защищёнными от изменений.
- Бюджет до PoC равен нулю.

## Текущая цель

Получить минимальную локальную страницу с одним WebMCP-инструментом и доказать его реальный вызов в поддерживаемом браузере.

## Следующий шаг

1. Проверить официальные требования и минимальный технический пример WebMCP.
2. Зафиксировать версии среды: ОС, Node/Python, браузер, Git.
3. Выбрать самый простой первый инструмент: `search_services`.
4. Создать статические тестовые услуги без подключения рабочего бота.
5. Реализовать один инструмент и проверить вызов.
6. Записать доказательство: команда запуска, результат, скрин/лог и ограничения.
7. Решение:
   - `GO` — реальный вызов стабильно повторяется;
   - `STOP` — вызов невозможен без неподходящих затрат или отсутствующей технологии.

## До решения GO запрещено

- Подключать реальную базу записей.
- Реализовывать все три инструмента.
- Покупать сервисы.
- Делать дизайн, рекламу, видео или интеграцию с Telegram.
- Commit/push без проверки секретов и явной фиксации результата.

## Условие завершения этапа 0

- Один инструмент вызывается реально, а не имитируется.
- Результат воспроизводится после чистого перезапуска.
- Нет секретов и реальных данных.
- Записаны точные команды и ограничения.
- Принято и записано решение `GO/STOP`.

## Точка продолжения

Начать с официальной технической проверки WebMCP и минимального PoC для `search_services`. Основные репозитории не открывать на запись.
