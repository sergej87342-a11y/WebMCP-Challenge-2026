# SECURITY

## Данные

- Только синтетические тестовые данные.
- Не копировать `.env`, токены, ключи, runtime JSON/SQLite и персональные данные.
- Секреты допускаются только через переменные окружения и никогда не попадают в Git.

## Действия

- `search_services` и `check_availability` — только чтение.
- `create_booking` — изменение состояния, поэтому требует `confirmed: true`.
- Перед записью повторно проверяется свободный слот.
- Ошибки не должны раскрывать внутренние пути, секреты или данные других записей.

## Git

Перед каждым commit:

1. Проверить `git status` и staged diff.
2. Проверить `.env`, ключи, токены, базы и персональные данные.
3. Запустить тесты.
4. Запустить `git diff --check`.
5. Записать результат в `CHECKPOINT.md`.

Commit и push выполняются только после проверки точного состава файлов.
