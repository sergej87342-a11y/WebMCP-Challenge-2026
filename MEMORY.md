## Решение по продукту

Делаем WebMCP-слой для существующей логики записи малого бизнеса. Демонстрационный вертикальный сценарий — запись клиента в салон.

Ровно три инструмента MVP:

1. `search_services`
2. `check_availability`
3. `create_booking`

Создание записи требует явного подтверждения человека. На первом этапе используем только тестовые данные.

## Стратегия

- Не рассчитывать на место в первой десятке; цель — законченная заявка и практический опыт.
- Сначала бесплатный минимальный PoC и один настоящий вызов инструмента.
- После PoC принять решение `GO/STOP` на основании фактов.
- Не переписывать существующего Telegram-бота и не расширять продукт раньше времени.

## Роли инструментов

- ChatGPT: архитектура, решения, тексты и контроль плана.
- Hermes: сервер, Git, команды и тесты.
- Operator: проверка браузерного сценария.
- Codex: сложный код, тесты и аудит после открытия лимита 29 августа.
- DeepSeek исключён из проекта из-за затрат времени на исправление ошибок.
